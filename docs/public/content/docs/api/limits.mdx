---
title: Limits
description: Field lengths, formats and request limits enforced by the API.
---

The API validates every request against these limits. A value outside them returns `400` with `validation.error` and the failing field in `errors[]`.

## Request limits

| Limit | Value |
| --- | --- |
| Ids per bulk request (`ids`, `user_ids`) | 1 to 100 |
| Page size (`limit`) | 1 to 100, default 25 |
| Cursor length | up to 200 characters |
| JSON nesting depth | 10 levels |
| Report range | up to 366 days |
| Clock duration | up to 24 hours |

## Users

| Field | Limit |
| --- | --- |
| `email` | valid address, up to 254 characters, unique, stored in lowercase |
| `first_name`, `last_name` | 1 to 100 characters, letters, spaces, apostrophes, dots and hyphens |
| `phone_number` | 6 to 20 characters: digits, spaces, `+`, `(`, `)`, `.` and `-` |
| `password` | 10 to 128 characters |
| `role` | `employee`, `manager` or `admin` |

## Teams

| Field | Limit |
| --- | --- |
| `name` | 1 to 100 characters |
| `description` | 1 to 500 characters, or `null` |
| `weekly_hours_target` | whole number from 1 to 80, default 35 |
| `work_start`, `work_end` | `HH:MM`, 24-hour clock; `work_end` after `work_start` |

## Clocks

| Field | Limit |
| --- | --- |
| `clocked_in_at` | epoch milliseconds, not in the future |
| `clocked_out_at` | after `clocked_in_at`, not in the future, at most 24 hours later |
| `note` | 1 to 500 characters, or `null` |

## Reports

| Field | Limit |
| --- | --- |
| `from` | epoch milliseconds, inclusive |
| `to` | epoch milliseconds, exclusive, at most 366 days after `from` |
| `granularity` | `day`, `week` or `month` |
