Time Manager enregistre le temps de travail. Les employés pointent leur arrivée et leur départ, les managers suivent leurs équipes grâce aux KPI, et les admins dirigent toute l'entreprise.

Vous pouvez utiliser Time Manager de trois façons :

- Par l'application web, que les employés et les managers utilisent au quotidien.
- Par l'API HTTP sous `/v1`, que vous appelez depuis vos propres outils.
- Par le SDK TypeScript `@time-manager/sdk`, un client typé pour l'API.

## Ce que vous pouvez faire

- Créer des utilisateurs et les organiser en équipes avec un manager, un objectif d'heures hebdomadaires et une journée de travail.
- Laisser les employés pointer leur arrivée et leur départ, et laisser les managers corriger ou ajouter des pointages pour leur équipe.
- Lire des KPI par utilisateur ou par équipe : temps travaillé, heures supplémentaires, jours travaillés et retards.
- Se connecter avec un mot de passe ou, pour les utilisateurs enregistrés, avec un compte Microsoft.

## Conventions de cette documentation

- Chaque identifiant, champ, code et scope apparaît en style `code`.
- L'API utilise `snake_case` sur le réseau. Le SDK convertit en `camelCase` : les exemples du SDK utilisent donc `firstName` là où l'API utilise `first_name`.
- Les horodatages sont des millisecondes epoch en UTC.
- Les statuts HTTP sont écrits en chiffres, par exemple `409`.
