---
title: Configuration
description: Every environment variable of the API, the database and the web build, with defaults.
---

You configure the stack through environment variables, usually in a `.env` file next to `docker-compose.yml`. Never commit this file.

In production (`NODE_ENV=production`), the API refuses to start if a required secret is missing or too short.

## Database

| Variable | Default | Meaning |
| --- | --- | --- |
| `POSTGRES_USER`, `POSTGRES_PASSWORD`, `POSTGRES_DB` | none, required | Database credentials. Compose builds `DATABASE_URL` from them. |
| `DATABASE_URL` | none | Connection string, when you run the API outside Compose. |
| `DATABASE_POOL_MAX` | `10` | Maximum database connections. |

## API

| Variable | Default | Meaning |
| --- | --- | --- |
| `NODE_ENV` | `production` | Environment. |
| `PORT` | `8000` | Port the API listens on. |
| `LOG_LEVEL` | `info` | Log verbosity. |
| `APP_TIMEZONE` | `Europe/Paris` | Company timezone used for `work_start`, `work_end` and report days. |
| `TRUST_PROXY` | `true` | Read the client address from the reverse proxy: `true`, `false`, a number of proxy hops, or a list of IP addresses. |
| `COOKIE_SECURE` | `false` in the Compose files | Set `true` behind HTTPS so the refresh cookie is `Secure`. The API defaults it to `true` in production. |
| `ALLOW_INSECURE_URLS` | `true` in `.env.example` | Lets a production-mode API accept an `http` or local `WEB_URL`. Use it for the local stack only and remove it behind HTTPS. |
| `CORS_ORIGIN` | `http://localhost:8080` | Origin allowed to call the API with credentials. |
| `WEB_URL` | `http://localhost:8080` | Where the API redirects the browser after Microsoft sign-in. |
| `JSON_BODY_MAX_DEPTH` | `10` | Maximum JSON nesting depth. |

## Secrets

| Variable | Default | Meaning |
| --- | --- | --- |
| `JWT_ACCESS_SECRET` | none, required | Signs access tokens. At least 32 characters in production. |
| `JWT_REFRESH_SECRET` | none, required | Protects refresh tokens. At least 32 characters. Use a different value from the access secret. |
| `JWT_ACCESS_TTL` | `15m` | Access token lifetime. |
| `JWT_REFRESH_TTL` | `7d` | Refresh token lifetime. |
| `ENCRYPTION_KEY` | none, required in production | Key for personal data at rest: base64, exactly 32 bytes. |
| `ENCRYPTION_KEY_ID` | `k1` | Identifier of the current encryption key. |
| `ENCRYPTION_KEYS_PREVIOUS` | none | Retired keys, as a comma-separated list of `id:base64`, still used to read old data. |
| `HASH_KEY` | none, required in production | Key for lookup hashes: base64, at least 32 bytes. |

<Callout type="warn">
Losing `ENCRYPTION_KEY` makes personal data unreadable. Store it with your backups, but separate from the database dumps.
</Callout>

## Admin seed

| Variable | Default | Meaning |
| --- | --- | --- |
| `SEED_ADMIN_EMAIL` | none, required | Email of the first admin. |
| `SEED_ADMIN_PASSWORD` | none, required | Password of the first admin. |

## Microsoft sign-in

All optional. See [Microsoft sign-in](./microsoft-sign-in) to register the application. Without the first two, `GET /v1/auth/microsoft` answers `auth.microsoft.unavailable` (503).

| Variable | Default | Meaning |
| --- | --- | --- |
| `MICROSOFT_CLIENT_ID` | empty | Application (client) id of your Microsoft Entra ID app registration. |
| `MICROSOFT_CLIENT_SECRET` | empty | Client secret value. It expires, so schedule a rotation. |
| `MICROSOFT_TENANT_ID` | empty | Directory (tenant) id, as a GUID. Required when the client id is set. Aliases such as `common` are not accepted. |
| `OAUTH_STATE_SECRET` | empty | Signs the sign-in state cookie. Required when the client id is set: at least 32 characters, different from the JWT secrets. |
| `MICROSOFT_REDIRECT_URI` | `http://localhost:8080/v1/auth/microsoft/callback` | Must match the redirect URI of the app registration exactly. |

## Rate limits

| Variable | Default |
| --- | --- |
| `USER_RATE_LIMIT_MAX`, `USER_RATE_LIMIT_WINDOW` | `100`, `1 minute` |
| `AUTH_RATE_LIMIT_MAX`, `AUTH_RATE_LIMIT_WINDOW` | `100`, `1 minute` |
| `AUTH_LOGIN_RATE_LIMIT_MAX`, `AUTH_LOGIN_RATE_LIMIT_WINDOW` | `10`, `1 minute` |
| `AUTH_ACCOUNT_RATE_LIMIT_MAX`, `AUTH_ACCOUNT_RATE_LIMIT_WINDOW` | `5`, `15m` |

See [rate limits](../api/rate-limits).

## Web build

| Variable | Default | Meaning |
| --- | --- | --- |
| `VITE_API_URL` | empty | API origin baked in at build time. Empty means the same origin, which nginx proxies. |
